# Kiwi Conversor

Conversor estático de arquivos para GitHub Pages.

## Conversões locais

- Imagens para PNG, JPG, WebP e BMP.
- Áudios compatíveis com o navegador para WAV PCM.
- JSON para CSV, texto ou HTML.
- CSV para JSON, texto ou HTML.
- Markdown para HTML ou texto.
- HTML e XML para texto.
- Qualquer arquivo para Base64 (`.base64`) ou GZIP.
- Arquivos `.base64` e `.b64` podem ser restaurados para o arquivo binário original.
- Arquivos `.gz` podem ser descompactados localmente.

Todos os arquivos são processados inteiramente no navegador. Não há upload, API ou servidor externo.

## Limitação intencional

Uma página estática não possui os conversores nativos instalados nos servidores de serviços como o Convertio. Por isso, a interface mostra somente formatos que podem ser produzidos com segurança no navegador do usuário.
